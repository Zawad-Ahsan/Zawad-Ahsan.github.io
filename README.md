# Zawad Ahsan — portfolio

Personal portfolio of Zawad Ahsan: software engineering, game design, research and stage magic.

Live at **https://zawad-ahsan.github.io**

## Layout

| Path | What it holds |
| --- | --- |
| `index.html` | All page content and sections |
| `style.css` | Colours, type, spacing and layout |
| `main.js` | Menu, scroll reveals, hero photo swap, card trick, contact form |
| `img/` | Photos and project images |
| `files/` | Downloadable CV, magic portfolio and research papers |

Plain HTML, CSS and JavaScript. No build step: edit a file, commit, and GitHub Pages republishes within a minute.

## Contact form

The form posts to [FormSubmit](https://formsubmit.co) and arrives by email. The first message after publishing sends a one-time activation email that has to be confirmed.
